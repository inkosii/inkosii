## 🚀 Featured Projects

### 1️⃣ Eskom Load Shedding Impact Analysis

**Goal:** Quantify and visualize how load-shedding affects economic output, municipal demand, and household behavior using real **StatsSA datasets**.

**What I built:**
- ✅ Sourced and cleaned StatsSA electricity, municipal, and GDP datasets
- ✅ Built time-series models (decomposition, rolling forecasts, regression analysis)
- ✅ Measured correlations between load-shedding severity and sectoral GDP impact
- ✅ Developed Streamlit dashboards + Gradio previews for stakeholder consumption
- ✅ Packaged with Docker for reproducible, scalable deployment

**Stack:** `Python` • `Pandas` • `NumPy` • `scikit-learn` • `Streamlit` • `Docker`
